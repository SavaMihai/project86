Hardware fixtures compare architectural registers, defined flag bits and expected RAM. They do not validate bus transfers, prefetch queues, every opcode, undocumented behavior, cycle accuracy or complete 286 compatibility. The main and extended counts are distinct; total **386,000**. The smaller focused debugging runs are not added to that total.

The CASSFAR milestone adds three provenance regressions, bringing that milestone's
packaging total to 32. Core/device tests now cover three BIOS capability probes
needed by original SELECT/KEYB. CPU instructions were unchanged; hardware fixtures
were not rerun. The compiler run interpreted 8,982,464,575 instructions and retained
11 unsupported I/O accesses (last port 06F7h). SELECT tests use private floppy swaps
and FAT16 targets; they do not establish native-window interaction, physical-device
behavior or hard-disk BIOS boot. Optional DOS Shell media is not included in the
tested installation. [CASSFAR.md](CASSFAR.md) records the precise scope, deliberate
GVIDO metadata differences and BIOS references.

The historical second-generation compiler run interpreted 8,878,533,227 instructions in 123.90 seconds. Its 25 packaging tests comprised the original 16 plus nine seed cases. That Mac build initially failed on undeclared sandbox inputs and passed after an input-file list was added. The COMSUBS milestone added four library/source-integrity cases, bringing its total to 29. The COMSUBS compiler run interpreted 8,882,770,835 instructions. Both compiler runs retain the diagnostic count of 11 unsupported I/O accesses (last port 06F7h); success is not complete device coverage. Neither milestone changed CPU/device semantics, reran hardware fixtures, exercised native gameplay or switched managed disks.

The complete source rebuild needs `FILES=64`, `BUFFERS=20`, `LASTDRIVE=C`, `COMMAND.COM /P /E:1024`, and a `BAKROOT` drive change from D: to C:. Original `VERSION.INC` switches are preserved. Wrappers assemble the published printer data; prebuilt CPI files and two intermediate objects are removed. The default retains the four pinned original libraries; the optional source variant removes COMSUBS/CASSFAR and builds our implementations before NMAKE. The build produces 60 generated distribution files, two unchanged profiles and the boot sector, including COMMAND.COM's VER source patch. Current logs/output ZIP/guest disk are under `.build/dos-command-editor-v2/`; `.build/dos-original-libraries/` and `.build/dos-cassfar/` preserve the earlier shell/library variants. Earlier [three-file](evidence/dos-rebuild.json), [62-file matching](evidence/full-dos-rebuild.json), VER and second-generation reports remain historical evidence.

The default again uses all four original libraries and compiler tools. The optional COMSUBS/CASSFAR source variant still uses binary SLIBCE/MEM; neither variant builds every linked byte from available source. Its utility tests use private floppies/hard disks, LASTDRIVE=Z for SUBST/JOIN, and COMMAND.COM on C: so joining or backing up A: cannot remove the running shell. DBCS interface coverage uses a guest-only range hook and does not certify localized DOS installation. See [COMSUBS validation details](COMSUBS.md). CuteMouse's corresponding-source package independently reproduced its driver, whose only upstream differences are 11 equivalent XCHG encodings. See [driver build](evidence/cutemouse-build.json) and [remaining library audit](SOURCE-COMPLETENESS.md). Bundling EMM386 does not establish support for its protected-mode code.

## Hands-on Mac check

1. In the open app, click the DOS display, enter `VER`, then `C:`, `CD WOLF`, `WOLF3D`.
2. Continue past startup, press Escape for the menu, press N, then choose Episode 1 and difficulty.
3. Walk, turn, open a door with Space and fire with Control; enable the sound button and listen for music and effects.
4. Save with F2, quit/relaunch the app, start Wolfenstein again and load the save.
5. Pause/resume, switch windows, and verify no lost input, audio backlog or storage error.

Do not mark these native acceptance checks complete until someone performs them.
